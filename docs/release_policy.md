# Release policy

The public repository contains code, schemas, documentation and synthetic or
explicitly redistributable fixtures. Real raw downloads, OCR pages, parsed exam
text and review outputs are ignored by Git by default.

Before any data release, verify at record and source level:

1. collection was approved;
2. licence evidence is retained;
3. `redistribution_allowed` is true;
4. the answer is `verified`;
5. parsing and human review are approved;
6. image assets have compatible rights;
7. duplicate and group leakage checks have completed.

Public accessibility alone is not redistribution permission.
